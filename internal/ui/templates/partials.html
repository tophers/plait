DNS

The device keeps its own DNS. Site IP routing still works; internal names may not resolve.

Resolvers must answer for both internal and public names. On tested mobile clients they handle all lookups, so if their site is down, name resolution fails everywhere. Prefer redundant resolvers at independently reachable sites with the same data; no failover order is guaranteed.

Mixing internal and public resolvers is not a primary/backup setup: private-name queries may reach a public resolver and get a negative answer even while the internal resolver works.

Separate with commas. Clients use them only when tunnel DNS is set.

Applies to the device's single interface and every site. Independent of gateway MTU.
